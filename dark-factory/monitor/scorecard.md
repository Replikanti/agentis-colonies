# Dark Factory — Monitor backtest scorecard

The monitoring peer of [`../evm-scorecard.md`](../evm-scorecard.md) /
[`../sealevel-scorecard.md`](../sealevel-scorecard.md). It is the **credibility backbone behind the
Path C live-watch sample**: a backtest showing the monitor would have **paged before** a known
incident (with a measurable lead time), plus a **quiet pre-incident window** showing a near-zero
false-positive rate. Generated by [`backtest.sh`](./backtest.sh).

## How a row is produced

`backtest.sh` points the monitor's **invariant-watcher verdict logic** at a fork pinned to
**historical block heights** around a known incident and replays it tick-by-tick:

```bash
# An ARCHIVE node is required to read state at an old block.
./backtest.sh \
  --rpc-url "$ARCHIVE_RPC" \
  --target 0xPROTOCOL \
  --incident-block <N> \
  --spec watch-spec.json \          # the SAME spec run-live-watch.sh emits / invariant-watcher consumes
  --lead-window 50 --post-window 10 \
  --pre-window 200 --quiet-lead 50  # the quiet window for the false-positive measurement
# or the single-invariant form:
#   --lhs-sig 'totalSupply()' --rhs-sig 'totalAssets()' --rel le
```

Each "tick" reads the same two on-chain quantities the **live** `invariant-watcher` reads
(`lhs_sig` and `rhs_sig`/`rhs_const`) — here via read-only `cast call --block <N>` — and applies the
**same deterministic relation** (`le | ge | eq`, with an optional margin-to-violation band). The
verdict tokens (`violated` / `margin` / `ok` / `no-read`) and the fuse-to-worst rule across a
multi-invariant SET are byte-for-byte the watcher's `verdict_of` / `worse_verdict`, so a backtest
**PAGE is exactly the page the live colony would raise**. The run reports:

- **Detection lead time** — `incident-block − first-page-block` (blocks before the event; convert to
  time via the chain's block interval, e.g. ~12 s/block on Ethereum L1).
- **Which watcher fired** — the watcher whose verdict produced the page (`invariant` for a solvency /
  reserve break; the SET path also names the member invariant). The other watchers
  (`governance` / `liquidity` / `flow` / `pause` / `oracle`) page off the same fork via their own
  read paths; this harness ships the **invariant** replay first (the broadest live-watchable class).
- **Quiet-window false-positive rate** — `false-pages / ticks` over a window strictly **before** the
  pre-exploit ramp (`--pre-window` blocks, guarded by `--quiet-lead`). After the shadow baseline this
  should be **0**.

A run is **PASS** when it paged (true positive) **and** the quiet window was clean (zero false pages).

**READ-ONLY / NON-CUSTODIAL:** every chain access is a `cast call` (a view read at a pinned block).
The harness never signs, never sends a transaction, never touches funds, and holds no key.
