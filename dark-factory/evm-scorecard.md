# Dark Factory — EVM calibration scorecard

The EVM peer of [`sealevel-scorecard.md`](./sealevel-scorecard.md). Generated by
[`calibrate-evm.sh`](./calibrate-evm.sh) over the five-class vuln+safe corpus in
[`evm-harness/contracts/`](./evm-harness/contracts). Detection is the real `classify_evm_llm`
(the multi-class EVM classifier); each verdict is the auditor's two-sided gate over a compiling
`revm` PoC run through the **real EVM** (`CONTROL OK:` + `INVARIANT VIOLATED:` + `exit 101`).

## Corpus

Five vulnerability classes, each a vuln contract (must reach **VERIFIED**) paired with a safe
control (must **NOT** verify — must reach **SAFE**). All compile under the pinned solc 0.8.26
(`evm-harness/compile.js`), and each vuln is written to be unambiguously its own class so the
classifier routes it correctly:

| Class | Vuln contract (expect VERIFIED) | Safe contract (expect SAFE) | Why unambiguous |
|---|---|---|---|
| `Reentrancy` | `ReentrancyVaultInsecure.sol` | `ReentrancyVaultSecure.sol` | external `.call{value:}` BEFORE the balance is zeroed (CEI violation); the safe variant zeroes first |
| `AccessControl` | `AccessControlVaultInsecure.sol` | `AccessControlVaultSecure.sol` | `setOwner()` with no `onlyOwner`; the safe variant gates it |
| `UncheckedCall` | `UncheckedCallVaultInsecure.sol` | `UncheckedCallVaultSecure.sol` | the balance is zeroed FIRST (not reentrancy), the only bug is the discarded `.call` success bool; the safe variant `require`s it |
| `OracleManipulation` | `OracleVaultInsecure.sol` | `OracleVaultSecure.sol` | price read straight from live spot reserves with no TWAP/bound (no `.call`, no overflow); the safe variant prices off an anchor + deviation bound |
| `IntegerOverflow` | `OverflowVaultInsecure.sol` | `OverflowVaultSecure.sol` | an explicit `unchecked { ... }` wrap on a balance underflow (no external call, no access gate); the safe variant uses solc-0.8 checked arithmetic |

Each pair lives alongside the M1–M3 Reentrancy + AccessControl pairs in
`evm-harness/contracts/`, with derived creation bytecode committed under `contracts/bin/`
(regenerate with `node evm-harness/compile.js`). The colony copies the per-run target to
`contracts/Target.sol` (git-ignored scratch) and drives its compiled bytecode through `revm`.

## Methodology

```bash
# AGENTIS = a built agentis binary; BACKEND defaults to claude (the only backend with a
# per-class router — mock falls back to the structural reentrancy heuristic and cannot
# confirm class routing). EVM_HARNESS_DIR defaults to ./evm-harness.
AGENTIS=/path/to/agentis ./calibrate-evm.sh            # writes ./evm-scorecard.md
AGENTIS=/path/to/agentis ./calibrate-evm.sh out.md     # or a chosen output path
```

`calibrate-evm.sh` runs `run-audit.sh --target <contract.sol> --evm-harness ./evm-harness` once
per corpus contract, parses the `VERDICT:` line, and tallies true-positives (vuln → VERIFIED),
false-VERIFIED (safe → VERIFIED — the hard blocker), and non-SAFE (safe → anything but SAFE).
The two-sided gate is the source of truth: a mis-routed class yields a non-VERIFIED verdict, never
a false-VERIFIED.
