## Integration-seam hunt guide
This zone is an integration seam — apply all 6 C15 heuristics:
1. ASSET/BALANCE MIS-ACCOUNTING across the boundary: does the adapter-reported value match the assets actually
   held after the external call round-trips? A mispriced share is theft (the top seam — the ERC4626
   share-price-vs-real-assets invariant across the integration boundary).
2. NEW/EXOTIC ADAPTER BIAS: prioritise the recently-added AaveV3Adapter — the under-audited tail nobody owns,
   not the widely-forked mainline.
3. GLOBAL VALUE-CONSERVATION BACKSTOP: FIRST find or prove ABSENT a protocol-wide withdraw-invariant + op-lock
   + cumulative-slippage cap; where it holds a single-adapter bug degrades to a REVERT, so the lens pays off
   only where per-adapter correctness is the ONLY barrier OR the code is FRESH.
4. CROSS-INTEGRATION COMPOSITION: can a flashloan via one adapter manipulate a position priced by another and
   extract, absent an operation-type lock?
5. SCOPE DISCIPLINE: attack the vault's OWN adapter/guard code, NOT the integrated pool — "the integrated
   protocol misbehaves" is out-of-scope-by-trust unless the target fails to defend against it.
6. FRESHNESS SYNERGY: this amplifies on this fresh integration-heavy vault; a mature hardened manager would
   revert, not drain.
Break invariant: "adapter-reported value == assets actually held across the external call".

## Integration-seam hunt guide
This zone is an integration seam — apply all 6 C15 heuristics:
1. ASSET/BALANCE MIS-ACCOUNTING across the boundary: does the wrapped price match the real feed value after
   the cross-boundary read? A mispriced share downstream is theft (the top seam).
2. NEW/EXOTIC ADAPTER BIAS: a recently-added feed wrapper is the under-audited tail — probe it before the
   mainline oracle.
3. GLOBAL VALUE-CONSERVATION BACKSTOP: FIRST find or prove ABSENT a protocol-wide withdraw-invariant + op-lock
   + slippage cap; where it holds a mispriced read degrades to a REVERT, so the lens pays off only where the
   wrapper's correctness is the ONLY barrier OR the code is FRESH.
4. CROSS-INTEGRATION COMPOSITION: can a manipulated feed compose with a flashloan-priced position elsewhere to
   extract, absent an operation-type lock?
5. SCOPE DISCIPLINE: attack the wrapper's OWN staleness/decimals handling, NOT the Chainlink feed — a feed that
   misbehaves is out-of-scope-by-trust unless the wrapper fails to defend against it.
6. FRESHNESS SYNERGY: this amplifies on a fresh integration-heavy target, not a way to crack a mature one.
Break invariant: "wrapper-reported price == fair feed price across the boundary".
DARK-FACTORY:BRIEF-END
