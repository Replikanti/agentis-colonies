A synthetic fixture: the declarations live in tables, not in prose.

## Scoping details

| Question | Answer |
|---|---|
| Deployment chains | The settlement layer and one rollup network |
| Trusted roles | The owner multisig may pause and set every parameter |
| Out of scope | Findings that need a compromised owner key are excluded |

## Token behaviour

| Behaviour | Supported |
|---|---|
| Fee-on-transfer tokens | No — every listed asset is a plain transfer token |
| Rebasing tokens | No |
| Tokens with more than 18 decimals | Not supported and not listed |
