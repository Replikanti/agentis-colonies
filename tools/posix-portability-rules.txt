# Rule table for tools/check-posix-portability.sh.
#
# Format: <id>|<grep -E pattern>|<why it differs on BSD/macOS>
#
# This table lives outside the script on purpose. The patterns are literal
# occurrences of the very constructs they match, so keeping them inline made the
# checker match its own source — and because `git ls-files` skips untracked
# files, that self-match stayed invisible until the file was committed.
#
# Every rule must cover the LONG-FORM flag as well as the short one. An earlier
# version matched only short flags, so `sed --in-place`, `grep --perl-regexp`,
# `readlink --canonicalize`, `date --date=`, `stat --format=`, `typeset -A`,
# `local -A` and `readarray` all sailed straight through — including constructs
# whose own explanation claimed to cover them.
#
# The two bash-4 rules are anchored to COMMAND POSITION, because unanchored they
# matched this repository's own lint error-message strings ("mapfile/readarray
# detected", "declare -A detected") and carried two false positives as debt. The
# anchor class must stay wide: `;`, `&`, `(`, `)`, `{`, `}`, `|` and the
# `if`/`elif`/`then`/`do`/`else` keywords, with [[:space:]] so a TAB works too.
#
# An `@exempt~<id>~<pattern>` row says: for rule <id>, a line that ALSO matches
# <pattern> is portable after all. That is how the `stat -c … || stat -f …`
# idiom is exempted — documented as portable from the first version but never
# implemented, so three allowlist rows were false positives carried as real
# debt. The `~` separator is deliberate: these patterns contain `|`, and the
# rule rows are split on `|`.
#
# Deliberately NOT listed, having been checked and found portable: `sort -V`,
# `head -c`, `sed -E`, bare `mktemp -d` (Apple's mktemp has had a no-template
# fallback since shell_cmds-198), and any `stat`/`date` site that already
# carries a `-f`/`-r` fallback on the same line.
grep-P|grep +(-[a-zA-Z]*P|--perl-regexp)|BSD grep has no Perl regex; use -E with a printf-built tab, or awk
sed-i-nosuffix|sed +(-i|--in-place)([[:space:]]|['"]|$)|BSD in-place sed takes a REQUIRED suffix; use python3, or a suffix then rm
sed-case-escape|sed [^|]*\\[uUlL]|GNU-only case-conversion escape; BSD sed has none — use awk toupper/substr
sed-word-boundary|sed [^|]*\\b|GNU-only word boundary; BSD sed has none — use [[:<:]] or awk
sha256sum|sha256sum|not on macOS; use shasum -a 256, or guard both on one line
find-printf|find .* -printf|BSD find has no -printf; use -exec stat or a portable loop
stat-c|stat +(-c|--format|--printf)|BSD stat uses -f; put both on one line with a fallback
date-d|date +(-d |--date)|BSD date uses -v; put both on one line with a fallback
readlink-f|readlink +(-f|--canonicalize)|BSD readlink has no -f; use the python3 realpath idiom
shell-realpath|^[^#]*[^.]\brealpath\b|not on macOS before 12.3; use the python3 realpath idiom
assoc-array|(^|[;&(){}|]|then |do |else |elif |if )[[:space:]]*(declare|typeset|local)[[:space:]]+-A|associative arrays need bash 4; macOS ships 3.2
mapfile|(^|[;&(){}|]|then |do |else |elif |if )[[:space:]]*(mapfile|readarray)([[:space:]]|$)|mapfile/readarray need bash 4; macOS ships 3.2
@exempt~stat-c~stat +(-f|--format=%[A-Za-z])
@exempt~date-d~date +(-r |-v|--reference)
