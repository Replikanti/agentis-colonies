# Rule table for tools/check-posix-portability.sh.
#
# Format: <id>|<grep -E pattern>|<why it differs on BSD/macOS>
#
# This table lives outside the script on purpose. The patterns are literal
# occurrences of the very constructs they match, so keeping them inline made the
# checker match its own source — and because `git ls-files` skips untracked
# files, that self-match stayed invisible until the file was committed.
#
# Deliberately NOT listed, having been checked and found portable: `sort -V`,
# `head -c`, `sed -E`, bare `mktemp -d` (Apple's mktemp has had a no-template
# fallback since shell_cmds-198), and any `stat`/`date` site that already
# carries a `-f`/`-r` fallback on the same line.
grep-P|grep +-[a-zA-Z]*P|BSD grep has no -P; use -E with a printf-built tab, or awk
sed-i-nosuffix|sed +-i +[^.]|BSD sed -i takes a REQUIRED suffix; use python3 or -i.bak + rm
sha256sum|sha256sum|not on macOS; use shasum -a 256, or guard both on one line
find-printf|find .* -printf|BSD find has no -printf; use -exec stat or a portable loop
stat-c|stat +-c|BSD stat uses -f; put both on one line with a fallback
date-d|date +-d |BSD date uses -v; put both on one line with a fallback
readlink-f|readlink +-f|BSD readlink has no -f; use the python3 realpath idiom
shell-realpath|^[^#]*[^.]\brealpath\b|not on macOS before 12.3; use the python3 realpath idiom
declare-A|declare +-A|associative arrays need bash 4; macOS ships 3.2
mapfile|mapfile |mapfile/readarray need bash 4; macOS ships 3.2
