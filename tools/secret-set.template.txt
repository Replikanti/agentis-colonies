secret-set.sh — store a forge token in your OS vault (#321)

Reads the token from stdin (no echo) and writes it via the chosen
backend. Prints the resulting `secret://...` URI on stdout for you
to paste into colony.toml in place of the plaintext token.

Backends (auto-detected via `command -v` in this order):

  1. libsecret  — Linux GNOME-Keyring (`secret-tool` from libsecret-tools)
  2. keychain   — macOS (`security` ships in /usr/bin)
  3. pass       — passwordstore.org (`pass` from your distro)

Override autodetect with `--backend libsecret|keychain|pass`.

Override the URI segments with `--service <s>` / `--account <a>`;
defaults are `agentis-colonies` / `<forge-type>-token`.

Failure modes (no token leak on any path):

  exit 0  ok — URI on stdout
  exit 2  usage error / no backend available
  exit 3  backend command failed
  exit 4  empty token / aborted by operator
